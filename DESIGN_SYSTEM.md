# Philosophy

Pradigi is not a traditional Learning Management System.

It is an AI Operating System.

Every interface should make users feel that:

- AI understands them.
- AI remembers them.
- AI is building their future.

Design should disappear.

Learning should remain.

---

# Design Principles

## 1. Calm

The interface should never overwhelm.

Every screen should feel clean, spacious, and focused.

---

## 2. AI First

The primary actor is AI.

Not buttons.

Not menus.

The interface revolves around AI decisions.

---

## 3. Workspace First

Pradigi is not course-centric.

It is workspace-centric.

Users own

- Workspace
- Memory
- Notebook
- Portfolio
- Sandbox

---

## 4. Future Oriented

The interface should always remind users who they are becoming.

Never focus only on today's lesson.

Always show career progress.

---

## 5. Minimal by Default

Remove visual noise.

Every component must justify its existence.

---

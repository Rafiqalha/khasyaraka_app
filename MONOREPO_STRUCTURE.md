# 📁 Pradigi Monorepo Structure

## 🏗️ Overview

Monorepo untuk aplikasi **Scout OS (Pradigi)** - Platform pembelajaran Pramuka dengan fitur Training, Cyber (Sandi), SKU, dan Survival.

```
pradigi/
├── scout_os_app/          # Flutter Mobile App (Frontend)
├── scout_os_backend/      # FastAPI Backend (Backend)
├── docs/                  # Dokumentasi proyek
└── infra/                 # Infrastructure (Docker, dll)
```

---

## 🔐 Environment Variables

### Frontend (`scout_os_app/lib/config/environment.dart`)
- `API_BASE_URL` - Backend API URL

### Backend (`scout_os_backend/app/core/config.py`)
- `DATABASE_URL` - PostgreSQL connection string
- `REDIS_URL` - Redis connection string
- `SECRET_KEY` - JWT secret key
- `GOOGLE_CLIENT_ID` - Google OAuth client ID

## 🎯 Quick Commands

### Frontend
```bash
cd scout_os_app
flutter pub get          # Install dependencies
flutter run              # Run app
flutter build apk        # Build Android APK
```

### Backend
```bash
cd scout_os_backend
pip install -r requirements.txt  # Install dependencies
alembic upgrade head              # Run migrations
python seed_cyber_data.py        # Seed cyber data
uvicorn app.main:app --reload    # Run dev server
```
